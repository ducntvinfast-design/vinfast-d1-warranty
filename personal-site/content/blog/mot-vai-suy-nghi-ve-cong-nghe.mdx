Đây là bài viết mẫu (placeholder) để minh hoạ các định dạng mà blog này hỗ trợ.

## Heading cấp 2

Nội dung MDX hỗ trợ đầy đủ Markdown, ví dụ **in đậm**, _in nghiêng_, và danh sách:

- Mục thứ nhất
- Mục thứ hai
- Mục thứ ba

### Heading cấp 3

Cũng hỗ trợ code block, ví dụ:

```ts
function greet(name: string) {
  return `Xin chào, ${name}!`;
}
```

Hãy thay nội dung này bằng bài viết chia sẻ kiến thức thật của anh.
